# 永貞國小114跨領域美感教育成果展
## 【美數．數美】幾何與比例的跨領域探索

本專案為 **苗栗縣頭份市永貞國民小學 114 學年度教育部跨領域美感教育卓越領航計畫**（創課方案 4.2 版）之官方線上成果展。

- **線上成果展網址**：https://binghong-xu.github.io/yongzhen-aesthetic-exhibition/
- **核心指導**：國立清華大學中文系 羅仕龍 教授
- **教學團隊**：徐秉鴻 老師、彭仁星 老師、黃欣怡 老師、鍾瑞蓉 校長
- **參展班級**：苗栗縣永貞國小 六年甲班 全體小藝術家

---

### 🎨 展覽核心主題
1. **數理邏輯 × 空間幾何**：費氏數列、黃金矩形、蒙德里安純粹分割、謝爾賓斯基三角形碎形、正四面體立體小夜燈。
2. **校本文化 × 蘆竹湳記憶**：走讀頭份三百年三合院聚落，古厝磚櫺幾何符號轉譯、日本傳統色紙版畫凸版拓印、作家專業落款。
3. **情意素養 × SDGs 永續**：SEL 社會情緒學習「酸甜哀怒」情緒調色盤、設計思考修補美學、SDG 4 優質教育、SDG 11 永續城鄉。

### 🛡️ 資料純淨度與個資合規檢驗
- **個資清除**：0 筆手機、0 筆 Email 殘留。
- **重複圖檔**：經 MD5 與 64-bit dHash 交叉核對，重複圖檔全數剔除，每幅作品僅保留 1 份高品質原件。
- **QR Code 移除**：經 jsQR 逐像素掃描，全數過濾並移除 19 筆純條碼圖檔。
